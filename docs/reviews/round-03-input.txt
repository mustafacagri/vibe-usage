### 2. B1–B7 Engelleyici Maddelerine Verilen Somut Çözümler ve Deterministik Testler

#### B1: Sağlayıcı Başına Nesil Sayacı (`providerGenerations = new Map()`)
- **Çözüm**: `service.cjs` içindeki global sayaç kaldırıldı; her sağlayıcı için bağımsız nesil (`providerGenerations.get(adapter.id)`) tutuluyor. Başka bir sağlayıcının refresh başlatması devam eden sağlayıcının neslini artırmaz. Katılan çağrılar P1 promise'ini paylaşır.
- **Test**: `Claude B1: Provider-scoped generation prevents concurrent refreshes from discarding results` testi elle çözülen ertelenmiş promise'lerle (`createDeferred`) yazıldı. Claude fetch'i beklerken Codex refresh başlatıldı; Claude fetch'i çözüldüğünde sonucun atılmadığı ve `ok` olarak kaydedildiği kanıtlandı.

#### B2: Guarded inFlight Temizliği
- **Çözüm**: `service.cjs` içinde `if (inFlight.get(adapter.id) === promise) inFlight.delete(adapter.id)` kalıbı uygulandı.

#### B3: 12 Saniye Sert Zaman Aşımı
- **Çözüm**: Her sağlayıcı çağrısı `Promise.race([adapter.fetch(account), timeoutPromise])` ile sınırlandı. 12 saniyede yanıt vermeyen yerel soketler veya HTTP istekleri `request_timeout` fırlatır ve inFlight map serbest kalır.

#### B4: Zombi Hesap Dirilmesini Önleme (`settingsRevision` ve canlı hesap kontrolü)
- **Çözüm**: `updateSettings` engellemesiz çalışır ve `settingsRevision` artırılır. Fetch tamamlandığında hesap hâlâ `settings.accounts` içinde mevcut değilse veya `configDir` değişmişse sonuç asla geri yazılmaz; silinen hesap dirilmez. Ayrıca `rebuild()` sonrası referans kopmasını önlemek için `provider.accounts` içindeki canlı hedef hesap güncellenir.
- **Test**: `Claude B4: Settings changes during in-flight fetch prevent zombie account resurrection` testinde fetch askıdayken kullanıcı B hesabını sildi; fetch çözüldüğünde B hesabının dirilmediği (snapshot'ta yalnızca A'nın kaldığı) kanıtlandı.

#### B5: Keşif Uzlaştırma Hatası ve Kullanıcı Özelleştirmesi Koruması
- **Çözüm**: `reconcileDiscovery` mutex kilidi (`discoveryRunning`) ile korundu. `discover()` hata verdiğinde (`catch`) kayıp sayacı ASLA artırılmaz (`continue`). Yalnızca temiz dönen ve hesabı içermeyen diziler için miss artırılır. Kullanıcı bir hesabı düzenlediğinde (etiket, sıra) `origin = 'user'` olarak işaretlenir ve 3 miss kuralından muaf tutulur.
- **Test**: `Claude B5: reconcileDiscovery does not increment misses on error and preserves user customizations` testinde 5 ardışık keychain/I/O hatası simüle edildi (0 silinme); ardından 3 temiz miss sonrası 'discovered' hesap silinirken 'user' etiketli hesabın korunduğu kanıtlandı.

#### B6: Antigravity E-posta Tabanlı Ayrım ve Atomik Pencere Birleştirmesi
- **Çözüm**:
  - `discover()` ve `fetch()` yerel servislerden dönen `userStatus.email` değerlerini okur. Farklı e-postalar varsa (`work@corp.com` vs `personal@gmail.com`) bunlar `antigravity:work@corp.com` ve `antigravity:personal@gmail.com` olarak iki AYRI hesap olarak listelenir.
  - Aynı hesaba ait sunucular birleştirilirken pencere nesnesi ATOMİK olarak seçilir: `resetsAt` değeri gelecekte olan taze pencere (>60s) önceliklidir (böylece sıfırlama öncesi %5'lik eski önbellek verisi seçilmez); aynı dönemde muhafazakâr kalan yüzde seçilir. Pencerenin tüm alanları (yüzde, resetTime, detail, source) bölünmeden tek kaynaktan aktarılır.
- **Test**: `Claude B6: Antigravity multi-server separates accounts by email and merges windows atomically with reset precedence` testinde hem farklı e-postalı sunucuların ayrı hesap olarak keşfi, hem de taze resetTime (95%) ile eski önbellek (5%) birleşiminde taze pencerenin atomik seçimi kanıtlandı.

#### B7: Bulut Değişkenleri Engelleme, `configDirExplicit` ve Kapsamlı Ayar Taraması
- **Çözüm**:
  - `cleanEnvironment` ve `launchEnvironment` tüm bulut değişkenlerini (`AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY`, `AWS_SESSION_TOKEN`, `ANTHROPIC_VERTEX_PROJECT_ID`, `CLAUDE_CODE_USE_BEDROCK`, `CLAUDE_CODE_USE_VERTEX`, `CLAUDE_CODE_USE_FOUNDRY`, `CODEX_HOME`, `OPENAI_BASE_URL`) Windows'ta case-insensitive, POSIX'te tam adıyla temizler.
  - `configDirExplicit: false` veya varsayılan profil başlatılırken `CLAUDE_CONFIG_DIR` kesinlikle `delete` / `unset` edilir.
  - `launchWarnings`, hem `.claude/settings.json`, hem `.claude/settings.local.json`, hem de profil `settings.json` dosyalarını tarar; `env` overrides ve `apiKeyHelper` varlığında açık uyarı üretir.
- **Test**: `Claude B7: cleanEnvironment blocks cloud/codex variables and launchWarnings checks setting files and helpers` testinde doğrulandı.

const { safeError, now, ProviderError } = require('../providers/common.cjs');

  trust_store_unavailable: 'İşletim sisteminin sertifika deposu okunamadı. Kurulumu ve desteklenen Node.js sürümünü kontrol edin.',
  no_limits_reported: 'Bu hesap için bildirilen aktif kota limiti bulunmuyor.',
  request_timeout: 'İstek zaman aşımına uğradı.'

const copy = value => structuredClone(value);

async function createService(options = {}) {
  const clock = options.clock || Date.now;
  const settingsPath = options.settingsPath || defaultSettingsPath();
  const adapters = options.providers || [
    require('../providers/codex.cjs').createCodexProvider(),
    require('../providers/claude.cjs').createClaudeProvider(),
    require('../providers/cursor.cjs').createCursorProvider(),
    require('../providers/antigravity.cjs').createAntigravityProvider()
  ];

  let settings = await loadSettings(settingsPath) || copy(DEFAULT_SETTINGS);
  let changed = false;

  for (const adapter of adapters) {
    const found = await adapter.discover().catch(() => []);
    for (const account of found) {
      if (!settings.accounts.some(a => a.id === account.id)) {
        settings.accounts.push({
          ...account,
          origin: 'discovered',
          primary: account.primary && !settings.accounts.some(a => a.providerId === adapter.id && a.primary)
        });
        changed = true;
      }
    }
  }

  settings = validateSettings(settings);
  if (changed) await saveSettings(settingsPath, settings);

  let providers = adapters.map(p => ({ id: p.id, name: p.name, status: 'pending', accounts: [] }));
  let pendingSave = Promise.resolve();
  const cooldown = new Map();
  const inFlight = new Map(); // providerId -> Promise
  const consecutiveMisses = new Map(); // accountId -> number
  const providerGenerations = new Map(); // providerId -> number
  let lastDiscoveryTime = now(clock);
  let discoveryRunning = null;
  let settingsRevision = 0;

  function rebuild() {
    for (const provider of providers) {
      const old = provider.accounts;
      provider.accounts = settings.accounts
        .filter(a => a.providerId === provider.id && a.enabled !== false)
        .map(a => {
          const previous = old.find(b => b.id === a.id);
          return previous && previous.configDir === a.configDir ? { ...previous, ...a } : { ...a, status: 'pending', windows: [] };
        });
    }
  }

  rebuild();

  function snapshot() {
    return copy({ providers, refreshing: inFlight.size > 0, settings });
  }

  async function reconcileDiscovery() {
    if (discoveryRunning) return discoveryRunning;
    discoveryRunning = (async () => {
      let modified = false;
      for (const adapter of adapters) {
        let found;
        try {
          found = await adapter.discover();
        } catch {
          // B5: Transient failure (keychain locked, network offline, etc.)
          // NEVER increment miss count on discovery error!
          continue;
        }
        if (!Array.isArray(found)) continue;
        const foundIds = new Set(found.map(a => a.id));

        for (const account of found) {
          consecutiveMisses.delete(account.id);
          const existing = settings.accounts.find(a => a.id === account.id);
          if (!existing) {
            settings.accounts.push({
              ...account,
              origin: 'discovered',
              primary: account.primary && !settings.accounts.some(a => a.providerId === adapter.id && a.primary)
            });
            modified = true;
          }
        }

        // Reconcile missing accounts: only auto-delete discovered accounts after 3 consecutive clean misses
        for (let i = settings.accounts.length - 1; i >= 0; i--) {
          const acc = settings.accounts[i];
          if (acc.providerId === adapter.id && acc.origin === 'discovered' && !foundIds.has(acc.id)) {
            const misses = (consecutiveMisses.get(acc.id) || 0) + 1;
            consecutiveMisses.set(acc.id, misses);
            if (misses >= 3) {
              settings.accounts.splice(i, 1);
              consecutiveMisses.delete(acc.id);
              modified = true;
            }
          }
        }
      }
      if (modified) {
        settings = validateSettings(settings);
        await saveSettings(settingsPath, settings);
        rebuild();
      }
    })();
    try {
      return await discoveryRunning;
    } finally {
      discoveryRunning = null;
    }
  }

  async function refreshSingleProvider(adapter) {
    const provider = providers.find(p => p.id === adapter.id);
    if (!provider) return;
    provider.lastAttemptAt = new Date(now(clock)).toISOString();
    const providerGen = (providerGenerations.get(adapter.id) || 0) + 1;
    providerGenerations.set(adapter.id, providerGen);
    const currentGen = providerGen;

    await Promise.all(provider.accounts.map(async account => {
      const attempt = now(clock);
      if ((cooldown.get(account.id) || 0) > attempt) return;
      account.lastAttemptAt = new Date(attempt).toISOString();

      let timer;
      const timeoutPromise = new Promise((_, reject) => {
        timer = setTimeout(() => reject(new ProviderError('request_timeout')), 12000);
        timer.unref?.();
      });

      try {
        const result = await Promise.race([
          adapter.fetch(account),
          timeoutPromise
        ]);
        clearTimeout(timer);

        if (account._gen && account._gen > currentGen) return; // newer fetch already completed
        account._gen = currentGen;

        // B4: verify account still exists in settings.accounts with matching configDir
        const currentAccount = settings.accounts.find(a => a.id === account.id);
        if (!currentAccount || currentAccount.configDir !== account.configDir || currentAccount.enabled === false) {
          return;
        }

        const stamp = new Date(now(clock)).toISOString();
        const windows = (result.windows || []).map(normalizeWindow);
        const targetAccount = provider.accounts.find(a => a.id === account.id) || account;
        targetAccount._gen = currentGen;

        if (result.status === 'no_limits_reported' || (!windows.length && result.status !== 'ok')) {
          targetAccount.windows = [];
          targetAccount.status = 'no_limits_reported';
          targetAccount.message = MESSAGES.no_limits_reported;
          targetAccount.fetchedAt = stamp;
        } else {
          for (const prior of targetAccount.windows || []) {
            if (!windows.some(w => w.id === prior.id)) {
              windows.push({ ...prior, stale: true, detail: 'Önceki ölçüm; son yanıtta bu kapsam bildirilmedi.' });
            }
          }
          targetAccount.windows = windows;
          targetAccount.status = 'ok';
          targetAccount.message = result.message || '';
          targetAccount.fetchedAt = stamp;
        }
        if (result.plan) targetAccount.plan = result.plan;
      } catch (error) {
        clearTimeout(timer);
        if (account._gen && account._gen > currentGen) return;
        account._gen = currentGen;

        // B4: verify account still exists in settings.accounts
        const currentAccount = settings.accounts.find(a => a.id === account.id);
        if (!currentAccount || currentAccount.configDir !== account.configDir || currentAccount.enabled === false) {
          return;
        }

        const targetAccount = provider.accounts.find(a => a.id === account.id) || account;
        targetAccount._gen = currentGen;
        const code = safeError(error);
        targetAccount.status = targetAccount.fetchedAt ? 'stale' : code;
        targetAccount.message = MESSAGES[code] || 'Kullanım verisi okunamadı. Bir sonraki yenilemede tekrar denenecek.';
        if (code === 'rate_limited') {
          cooldown.set(account.id, attempt + (error.retryAfterSeconds || 120) * 1000);
        }
      }
    }));

    const allOk = provider.accounts.length > 0 && provider.accounts.every(a => a.status === 'ok' || a.status === 'no_limits_reported');
    provider.status = allOk ? 'ok' : provider.accounts.some(a => a.fetchedAt) ? 'stale' : (provider.accounts[0]?.status || 'unavailable');
    if (allOk || provider.accounts.some(a => a.status === 'ok')) {
      provider.fetchedAt = new Date(now(clock)).toISOString();
    }
    provider.message = provider.accounts.length ? '' : 'Bağlı hesap bulunamadı.';
  }

  function getOrStartProviderRefresh(adapter) {
    if (inFlight.has(adapter.id)) {
      return inFlight.get(adapter.id);
    }
    const promise = refreshSingleProvider(adapter).finally(() => {
      if (inFlight.get(adapter.id) === promise) {
        inFlight.delete(adapter.id);
      }
    });
    inFlight.set(adapter.id, promise);
    return promise;
  }

  async function refresh(providerId) {
    if (providerId !== undefined && !adapters.some(a => a.id === providerId)) {
      throw Error('invalid_provider');
    }

    // Periodic discovery reconciliation (every 60s)
    if (now(clock) - lastDiscoveryTime > 60000) {
      lastDiscoveryTime = now(clock);
      await reconcileDiscovery().catch(() => {});
    }

    if (providerId !== undefined) {
      const target = adapters.find(a => a.id === providerId);
      await getOrStartProviderRefresh(target);
      return snapshot();
    }

    // Full refresh: ensure all providers are started in parallel and awaited without skipping
    await Promise.allSettled(adapters.map(adapter => getOrStartProviderRefresh(adapter)));
    return snapshot();
  }

  async function updateSettings(patch) {
    const operation = pendingSave.catch(() => {}).then(async () => {
      settingsRevision++;
      let updatedPatch = { ...patch };
      if (patch.accounts) {
        // B5: Preserve origin and mark user customizations as origin = 'user'
        updatedPatch.accounts = patch.accounts.map(acc => {
          const existing = settings.accounts.find(a => a.id === acc.id);
          const existingOrigin = existing?.origin || 'discovered';
          const labelChanged = acc.label !== undefined && existing && acc.label !== existing.label;
          const primaryChanged = acc.primary !== undefined && existing && acc.primary !== existing.primary;
          const origin = (labelChanged || primaryChanged || acc.origin === 'user') ? 'user' : (acc.origin || existingOrigin);
          return { ...acc, origin };
        });
      }
      const next = validateSettings({ ...settings, ...updatedPatch });
      await saveSettings(settingsPath, next);
      settings = next;
      if (patch.accounts) rebuild();
      return snapshot();
    });
    pendingSave = operation;
    return operation;
  }

  return { snapshot, refresh, updateSettings, reconcileDiscovery };
}
